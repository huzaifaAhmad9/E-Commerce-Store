# 🛒 E-Commerce Store App

![Flutter](https://img.shields.io/badge/Flutter-v2.5.0-blue.svg) ![Dart](https://img.shields.io/badge/Dart-v2.14.0-blue.svg) ![License](https://img.shields.io/badge/License-MIT-green.svg)

The **E-Commerce Store App** is a robust Android application built in Java that allows users to explore, add to cart, and purchase products seamlessly. Designed for scalability and user engagement, this app provides an intuitive interface and integrates core e-commerce features.

## 🚀 Features

- 🛍️ **Product Catalog**: Browse a wide range of products with detailed descriptions and images.
- 🔍 **Search & Filter**: Find products quickly using advanced search and category-based filters.
- 🛒 **Shopping Cart**: Add, remove, or update items in the cart with real-time price updates.
- 💳 **Checkout & Payment**: Secure and streamlined checkout process with multiple payment options.
- 🖼️ **Product Images Carousel**: View products with high-quality images in a carousel view.
- 🔔 **Notifications**: Get updates on offers, order status, and more.
- 🧑‍💼 **User Profiles**: Manage account details, order history, and saved items.
- 📱 **Responsive Design**: Optimized for a variety of Android devices and screen sizes.
  

## 📦 Installation

Follow these steps to get started with the Corona Tracker App:

1. **Clone the repository**:
   https://github.com/huzaifaAhmad9/E-Commerce-Store.git

2. **Open the project**: Open the project folder in Android Studio.

3. **Sync Gradle**: Allow Android Studio to sync Gradle dependencies automatically.

4. **Build the project**: Click on Build > Make Project to ensure there are no build errors.

5. **Run the app**: Connect an Android device or emulator and click on Run.


## 🛠 Built With

- Java: Core programming language for building the app.
- Android SDK: Android libraries and tools for development.
- SQLite: Local database for storing user data and cart items.
- Retrofit: For seamless API integration.
- Glide: For efficient image loading.
- Firebase: Used for notifications and analytics.
